# 灵犀面试

姜小白的 Java / 后端面试笔记站点，基于 VuePress + vuepress-theme-hope。

面试题内容整理自开源资料，站点品牌、主题样式与全文解锁逻辑为独立定制。

## 功能

- 面试题知识体系（Java / 数据库 / 计算机基础 / 分布式 / 系统设计 / AI）
- 点击「阅读全文」关注公众号「架构师姜小白」，回复「验证码」解锁
- 关于作者、GitHub 与个人博客入口

## 本地启动

```bash
pnpm install
pnpm docs:dev
```
